## The game

**Grimmwick — Relight the Night** — a cute-spooky side-scrolling 3D platformer for iPhone, iPad, and Mac, launching **October 2026**. All-ages (4+ rating). A tiny kid named Pip relights a Halloween town where the festival never ends. Tone: **charming first, spooky second, never scary** — storybook Halloween, not horror.

## The sound

**"Danny Elfman meets Luigi's Mansion."** Orchestral cute-spooky. Core palette:

- Music box · celesta · glockenspiel
- Theremin (or a singing-saw feel)
- Pizzicato strings
- Tuba + low bassoon (the comedy bottom end)
- Light "ooh" choir, sparingly

Minor keys that still smile. Waltz feels at home here. Think trick-or-treating as an orchestra piece.

**Reference tracks:** Luigi's Mansion main theme · *This Is Halloween* (instrumental energy, not the melody) · Costume Quest OST (Peter McConnell) · Edward Scissorhands main title (for wonder, dialed to kid-size).

## Technical

- Seamless loops — deliver pre-trimmed to the loop, or give exact loop points.
- WAV, 48kHz. We encode to .m4a ourselves. Stems welcome but optional.
- Leave ~1dB headroom; no brick-wall limiting. **Must still read on an iPhone speaker** — check the mix on a phone before delivering.
