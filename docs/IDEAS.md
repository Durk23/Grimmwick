## New game ideas (untriaged)
- **ADVENTURES OF PIP (the Arc, step 2) — concept forming (Aug 2026):** Pip travels town to town saving each from a different situation — "like Grimmwick was," but each town its own theme (not all Halloween). Owner asked about RPG-style (recent Switch Pokémon, mobile-shaped). Assessment: very makable on our engine — free-roam zoned world (hub-town tech scaled up), turn-based combat is easier than platforming physics; the true cost is content volume (writing, quests, balance). Recommended shape: adventure-RPG hybrid — towns + routes, NPC quests, HP/gear/ability progression, each town arc capped by a themed dungeon + boss. Open questions: turn-based vs real-time combat? Companions/creatures vs solo Pip with per-town abilities? Creature-collector deferred to game #3 if desired.
